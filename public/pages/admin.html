Target Selection

Choose where to send the videos - either auto-detect from bot's groups/channels or enter manually.

Examples: @mychannel, -1001234567890, https://t.me/mychannel

💡 How to find Topic ID:
1. Open your topic in Telegram
2. Copy the topic link (e.g., https://t.me/c/3274479338/2)
3. The last number is your Topic ID (in this example: 2)
4. Use the ID Converter Tool for easy conversion

ℹ️ Topic ID is only needed for groups with topics/forums enabled. Leave empty for regular groups or to send to general chat.
